# v0.1.19

`v0.1.19` 是 [`v0.1.18`](v0.1.18.md) 的修复版本，无 breaking 变更。`v0.1.18` 的二进制与镜像
已发布且可用，但发布流水线对已发布镜像运行的 quickstart 冒烟失败，MCP Registry 元数据因此
没有发布；本版本修复该问题并补上发布。

## 修复

- **成本拒绝优先于预算拒绝**：成本闸门拒绝的语句若同时超出调用方的扫描行数预算
  （`budget` 的 `maxEstimatedScannedRows`），此前返回 `BUDGET_EXCEEDED`，提示“等待预算重置后
  重试”，对全表扫描这类语句并无帮助；现在返回 `COST_EXCEEDED`，带缩小范围与索引提示。
  受治理工具与 `execute_sql` 一致；闸门放行的语句仍受预算约束。`v0.1.18` 起全表扫描按表的
  行数计入预算，使这一问题更常出现。未配置扫描行数预算的部署不受影响。
- **`validate` 的密钥根目录**：`validate` 现在按配置的 `server.secrets.allowedRoots` 读取
  `${file:}` 密钥，与 `serve` 一致；此前只认默认的 `/run/secrets`、`/var/run/secrets`。

## 发布流程

quickstart 冒烟此前只对已发布的镜像运行，问题在发布之后才暴露。现在：

- PR CI 与 tag 流水线在发布任何产物之前，用本次提交构建的镜像运行 quickstart 冒烟
  （`make quickstart-check`），失败则不发布；
- 已发布镜像的冒烟保留，作为发布后的确认；
- `make release-preflight` 增加控制台检查与协议冒烟，覆盖 PR CI 与 tag 流水线的全部检查，
  打 tag 前必须在该提交上通过。

## 升级

从 `v0.1.18` 升级无需改动配置；从更早版本升级见 [`v0.1.18` 的迁移](v0.1.18.md#迁移)。

## 验证

在 tag 提交上本地运行 `make release-preflight RELEASE_VERSION=0.1.19`：`ci-full`（三库
integration 与 MCP e2e）、控制台 vitest / vue-tsc / 构建、协议冒烟、GoReleaser 快照与归档校验、
Registry 元数据校验、镜像 label / SBOM 与 quickstart 冒烟、ModelScope 冒烟全部通过。新增测试
覆盖成本拒绝与预算的先后（受治理工具与 `execute_sql`）以及 `validate` 的密钥根目录。
